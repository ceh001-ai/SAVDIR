This manual outlines the precise 6-Step Deployment Protocol to configure, host, and publish your personal learning hub (SAVDIR) on your private GitHub account. Follow this guide to activate your cloud deployment pipeline with continuous updates using GitHub Actions.

📦 Step-by-Step Deployment Runbook

01
Extract the Downloaded Workspace ZIP

Locate the downloaded archive from Google AI Studio (usually named with the project workspace ID).

  • Right-click the file and select Extract All... or use terminal commands.
  • Store the extracted files in a neat, permanent workspace folder (e.g., Documents/SAVDIR).
02
Initialize Git Control Locally

Open your local shell (macOS Terminal, Git Bash, or Windows Command Prompt) and target the directory:

cd path/to/your/extracted/SAVDIR-folder

Initialize git with the standard master branch name main:

git init -b main
03
Create a Blank GitHub Repository

Open your web browser and navigate to github.com.

  • Click the "+" button in the top right, select New repository.
  • Set the name to SAVDIR (using lowercase is fine too).
  • Make sure the repository visibility is set to Public.
  • Leave Add README file, Add .gitignore, and Choose a license completely unchecked.
  • Click Create repository and copy the generated SSH or HTTPS clone URL.
04
Link & Push Local Assets to GitHub

Add all source files to the local staging index, commit, and link to GitHub:

git add .
git commit -m "Initial commit: SAVDIR Personal Learning Hub"

Bind the remote URL and push (replace the URL below with your actual copied URL):

git remote add origin https://github.com/YOUR_USERNAME/SAVDIR.git
git push -u origin main
05
Configure GitHub Actions Permissions

To let the workflow compile code and push the compiled web app bundle to your hosting branch automatically, configure the write permission:

  • Go to the **Settings** tab on your GitHub repository page.
  • Under the "Security" menu in the left sidebar, click on **Actions** → **General**.
  • Scroll to the bottom of the page to find the **Workflow permissions** block.
  • Check **Read and write permissions**.
  • Click **Save** to apply.
06
Set Hosting Branch & View Live Web App

Once your workspace files are uploaded, the GitHub Actions deployment workflow will build the static index automatically. After the action completes:

  • Navigate to repository **Settings** → **Pages** in the left sidebar.
  • Under "Build and deployment" → "Source", choose **Deploy from a branch**.
  • Select **gh-pages** from the branch dropdown, then click **Save**.
  • Wait a few seconds. Refresh the page to see your live URL at the top of the tab!

⚠️ Crucial Base URL Instruction

GitHub Pages serves user websites in a subfolder relative to your repository name (e.g., https://yourusername.github.io/SAVDIR/). Your app is pre-configured with a base URL matching SAVDIR. If you name your repository anything else (e.g., my-notes), you must open vite.config.ts and update the base: '/SAVDIR/' line to match your exact repository name, then commit and push the change.
